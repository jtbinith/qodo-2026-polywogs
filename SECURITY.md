# Security

## Reporting a vulnerability
Please don't open a public issue. Report it privately instead: [Report a vulnerability](https://github.com/jtbinith/qodo-hack-2026/security/advisories/new). Only the maintainer can see it.

Include what you found, how to reproduce it and what it could let someone do.

## Known gaps
Known limits are listed in [AGENTS.md](AGENTS.md#known-gaps) and the [threat model](docs/THREAT-MODEL.md). They don't need a private report.
